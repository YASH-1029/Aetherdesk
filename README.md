# AetherDesk

AI-powered ticket management platform designed to streamline support workflows and automate ticket handling operations.

## Features

- AI-assisted ticket summarization and categorization
- Role-based ticket management system
- Real-time ticket lifecycle tracking
- Admin dashboard with analytics and filtering
- Secure authentication and authorization
- Responsive frontend for seamless cross-device usability

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Prisma ORM
- PostgreSQL

### AI Integration
- LangChain
- Gemini API
